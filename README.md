# GCDP_MSG

**온열질환 위험 감지 손목밴드**의 경고 SMS 수신 화면을 재현한 모바일 웹앱 데모입니다.

실제 장치는 [`geumbang1/gcdp-heat-risk-alert-wristband`](https://github.com/geumbang1/gcdp-heat-risk-alert-wristband)
— ESP32-C3 + TMP117(체온) + MAX30102(심박) + BE-220(GNSS) 조합으로,
LTE-M 망을 통해 보호자에게 SMS를 전송합니다. 이 저장소는 그 **수신 측 화면**을
발표·시연용으로 흉내 낸 것입니다. 실제 통신은 하지 않습니다.

## 데모 조작

**화면을 빠르게 두 번 터치하면 경고 메시지가 즉시 도착합니다.**

- 메시지 시각은 실제 도착한 시각으로 찍힙니다
- 받은 메시지는 `localStorage`에 남아 새로고침해도 유지됩니다
- 메시지가 쌓이면 실제 메시지 앱처럼 위아래로 스크롤됩니다
- 대화 목록 화면에서 두 번 터치하면 안 읽음 배지가 올라갑니다
- 기록을 지우려면 **⋮ → 대화 내용 삭제**

버튼·입력창 위에서는 두 번 터치해도 메시지가 오지 않습니다. 버튼을 누르는
동작과 겹치지 않도록 걸러 둔 것입니다.

## 메시지 형식

펌웨어 [`sendAlertSms()`](https://github.com/geumbang1/gcdp-heat-risk-alert-wristband/blob/HEAD/firmware/src/main.cpp#L1072-L1084)
가 실제로 보내는 본문을 그대로 따릅니다.

```
SOS HELP REQUEST
HR: 84.2 bpm
TEMP: 36.55 C
LOC: 13.736717,100.523186
```

값은 매번 새로 생성됩니다 — 심박 80~90 bpm, 체온 36.4~36.7 °C,
좌표는 방콕 인근입니다.
센서 값이 없을 때 펌웨어가 `N/A`를 넣는 동작도 동일합니다.

## UI

삼성 One UI 메시지 앱 화면을 기준으로 구성했습니다.
치수는 1080px 캡처 / DPR 2.75(= 393dp 논리폭) 기준으로 환산했습니다.

- 대화 목록 — 검색, 대화 1건(미리보기·시각·안 읽음 배지), 새 대화 버튼
- 앱바 — 뒤로가기, 프로필, 발신번호 `+82 10 3232 1976`, 더보기
- 스미싱 안내 배너 + `수신 차단` / `메시지 신고` 버튼
- 날짜 구분선 (`8월 13일 목요일` 형식, 날짜가 바뀌면 자동 삽입)
- 좌측 회색 수신 버블 / 우측 파란 발신 버블 + 시각 (`오전 3:27` 형식)
- 하단 입력바 — 갤러리, 카메라, 첨부, 입력창, 이모지, 음성, 전송

상태바(시계·배터리 줄)는 일부러 그리지 않습니다. 실기기에서는 폰 자체
상태바가 위에 표시되므로 함께 그리면 두 줄로 겹쳐 보입니다.

### 버튼 동작

화면 안의 모든 버튼이 실제로 동작합니다.

| 버튼 | 동작 |
| --- | --- |
| 뒤로 | 대화 목록으로 이동 |
| 프로필 / 번호 | 전화 걸기·번호 복사·연락처 추가·수신 차단 시트 |
| 더보기 ⋮ | 대화 내용 삭제 · 알림 켜기/끄기 · 스팸 신고 · 번호 복사 |
| 수신 차단 / 메시지 신고 | 확인 창 → 안내 배너 제거 (상태 저장) |
| 갤러리 / 카메라 | 실제 사진 선택·촬영 → 사진 메시지 전송 |
| 첨부 + | 연락처 · 위치 공유 · 파일 · 일정 시트 |
| 입력창 / 전송 | 입력하면 음성 버튼이 전송 버튼으로 바뀜, 우측 버블로 전송 |
| 이모지 | 이모지 팔레트 → 입력창에 삽입 |
| 음성 | 음성 인식으로 받아쓰기 (지원 브라우저 한정) |
| 말풍선 길게 누르기 | 복사 · 전달 · 삭제 |
| 대화 목록의 검색·⋮·새 대화 | 각각 안내 토스트 / 시트 / 대화방 열기 |

## 홈 화면에 추가

브라우저로 열었을 때만 상단에 안내 줄이 나옵니다. 홈 화면에서 실행하면
안내 줄 없이 전체화면으로 뜹니다.

- **갤럭시(크롬·삼성 인터넷)** — `설치`를 누르면 바로 설치 창이 뜹니다
  (`beforeinstallprompt`).
- **아이폰** — iOS 사파리에는 자동 설치 프롬프트가 **없습니다**.
  `공유 → 홈 화면에 추가 → 추가`를 직접 눌러야 하며, 앱 안의 `방법` 버튼이
  그 순서를 알려줍니다. 크롬·네이버 등 다른 iOS 브라우저에서는 안 되고
  **사파리로 열어야** 합니다.

아이콘은 삼성 메시지 앱 아이콘(파란 그라디언트 + 흰 말풍선)을 따랐습니다.
iOS는 SVG 아이콘을 쓰지 못해서 `apple-touch-icon.png`(180×180)를 따로 둡니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (의존성 없는 단일 파일) |

## 실행

```bash
python -m http.server 8080
# http://localhost:8080
```

컨테이너로:

```bash
docker build -t gcdp-msg .
docker run --rm -p 8080:80 gcdp-msg
```

## 배포

Coolify로 `msg.uxo.kr`에 올립니다. 절차는 [DEPLOY.md](DEPLOY.md)를 보세요.
